# Riglyph v0.16.2 — Geometry and clipping fixes

This patch release corrects selective transform inheritance and hardens shared clipping geometry across JavaScript CPU, WebGL2 and Rust native rendering.

## Changes

- Correct transform inheritance under nonuniform scale, reflection and shear, verified against independent numerical observations.
- Handle valid concave, reflected and small/large clipping polygons robustly, with bounded decomposition and triangle expansion.
- Preserve strict rejection of invalid geometry by default. Add explicit `compatible` clipping policy with deterministic even-odd coverage for proper self-intersections and structured warnings.
- Expose geometry policy and diagnostics through packet preparation, WebPlayer and HeadlessRenderEngine. The CLI supports `--clipping-policy strict|compatible` and `--debug-geometry <new-file.jsonl>`.
- Add complete synthetic animation pixel regressions and improve browser CI installation reliability.

## Validation and limitations

The accepted implementation passed 466 Node tests, build/type checks, browser/framework smoke, and native tests on Linux, Windows and macOS. Private Hiyuki verification covered all 120 frames: JS/Rust RGBA matched byte-for-byte, all WebGL frames rendered, and MP4/H.264 plus alpha WebM/VP9 exports were decoded and checked. Seven selected frames were compared with the supplied Java Viewer. Private assets and reference executables are not distributed.

Hiyuki's source deform creates a genuine self-intersection at frame index 49. The Java Viewer reproduces this source defect. Use `compatible` to render that asset uninterrupted; this policy does not promise official parity for malformed polygons. Strict mode remains the default.

Supported source profile remains Spine Binary 4.1.23. Universal IR 1.0.0, native binary 0.1.0, C ABI 1 and packet protocol 1 are unchanged. This is a pre-1.0 release; arbitrary third-party asset compatibility is not claimed. See [rendering conformance](https://github.com/drhspfn/riglyph/blob/main/docs/rendering-conformance.md) for detailed evidence and limits.

## Install and export

```sh
npm install @riglyph/player-web@0.16.2
npm install --save-dev @riglyph/cli@0.16.2
npm exec -- riglyph render skeleton.ir.json --images ./textures --clip idle --backend js --clipping-policy compatible --format webm --alpha --out animation.webm
```

Video requires FFmpeg and ffprobe. For native rendering, extract the matching archive, set `RIGLYPH_NATIVE_BIN` to its executable and select `--backend native-cpu`.

All nine `@riglyph/*` npm packages are versioned 0.16.2 together. Native archives include executable, shared library, C header, license, version metadata and SHA-256 checksums:

- `riglyph-native-v0.16.2-windows-x64.zip`
- `riglyph-native-v0.16.2-linux-x64.tar.gz`
- `riglyph-native-v0.16.2-macos-arm64.tar.gz`
