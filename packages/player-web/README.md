# @riglyph/player-web

The optional constructor setting `geometry: {clippingPolicy: 'compatible',
onGeometryWarning: warning => console.warn(warning)}` enables explicit even-odd
handling of self-crossing masks. Default clipping remains strict. The public
package exports `ClippingPolicy`, `GeometryDiagnostic` and `PacketOptions`.
See [rendering conformance](https://github.com/drhspfn/riglyph/blob/main/docs/rendering-conformance.md)
for limitations and geometry diagnostics.

Browser player for portable Riglyph skeletal scenes (IR + PNG pages). Version 0.15.1 preview.

## Install

```sh
npm install @riglyph/player-web
```

## Load and play

```ts
import { createPlayer } from '@riglyph/player-web';
const player = await createPlayer({canvas:document.querySelector('canvas')!, assetUrl:'/assets/demo/manifest.json',autoResize:true,enableControls:true});
const clips = player.animations();
if (clips[0]) player.play(clips[0].id,{loop:true});
player.setCamera({mode:'fit-scene',padding:1});
// Call player.dispose() when removing the canvas.
```

The manifest is generated by `@riglyph/cli convert`. HTML playback controls are intentionally separate from this package; pointer/wheel camera controls are opt-in via `enableControls`.

### Camera

`setCamera({mode:'fit-scene',padding:1})` fits with no artificial margin; omitting `padding` retains the `1.25` default. Auto-fit preserves the scene aspect ratio. Zoom/pan switch into fixed camera mode until auto-fit is requested again.

### Playback

The player provides `animations`, `skins`, `play`, `pause`, `resume`, `seek`, `setLoop`, `setSpeed`, `setDefaultMix`, `transitionTo`, `enqueue`, `on`, `status`, `diagnostics` and `dispose`. See the [public web player guide](https://github.com/drhspfn/riglyph/blob/main/docs/web-player.md) and [React/Next examples](https://github.com/drhspfn/riglyph/blob/main/docs/frameworks.md).

This is an independently developed toolkit; currently supported build-time input is Spine Binary **4.1.23** only. No full third-party runtime parity is claimed.
