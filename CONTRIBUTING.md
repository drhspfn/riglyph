# Contributing to Riglyph

Use original algorithms and self-authored fixtures. **Do not** include code, pseudocode reconstructed from, or assets extracted from official Spine Runtime, third-party ports, reverse-engineered proprietary software or closed games. Follow the Agent A/B clean-room boundary: only behavior specifications and independently observed outputs may reach this repository. Document provenance and license for each contribution; report suspected contamination privately via SECURITY.md. Run `npm ci --offline --ignore-scripts && npm test && npm run typecheck && npm run pack:check` and update tests and compatibility statements. Format changes require a separate importer plugin and a documented Universal IR migration policy. Public contributions are only accepted after repo publication and policy review.
