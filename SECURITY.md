# Security policy

Supported preview: v0.15.1 candidate (not published). Please **do not open public issues for vulnerabilities**. After creating the GitHub repository, enable GitHub private vulnerability reporting in Settings → Security → Code security and analysis. Until configured, the owner must publish a vetted security contact in this document. **No contact address is assumed or invented.** Treat malformed/untrusted `.skel`, `.atlas`, JSON and PNG as hostile input; convert locally and enforce memory limits. Never submit commercial game assets or credentials in bug reports.
